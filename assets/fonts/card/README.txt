Fonts used ONLY by the PNG preview of the membership card (app/services/Membership/Card/CardPng.php).

Liberation Sans and Liberation Serif, Copyright (c) 2012 Red Hat, Inc. (with Reserved Font Name Liberation), licensed under the SIL Open Font
License 1.1 (see OFL.txt in this folder). They are metric-compatible with Helvetica and Times, the PDF core fonts of the real card, so the preview
lines have the same width as the PDF. The PDF itself embeds no font file.

Delete this folder if you do not want the PNG preview to use TrueType fonts: it then falls back to GD's plain bitmap fonts.
